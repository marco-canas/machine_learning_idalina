
# Cuadernos de estudio de la consolidación del modelo predictor

## Secuencia

01. Carga e ingeniería de características
02. Reducción dimensional
03. Preparación de datos para MLP
04. Búsqueda de hiperparámetros
05. Entrenamiento MLP por dataset
06. Comparación y selección del mejor modelo
07. Serialización del modelo `.pkl`
08. Generación del dashboard
09. Generación de Excel de resultados
